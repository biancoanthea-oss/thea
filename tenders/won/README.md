# Won bids

The most valuable folder here. A won tender is proof that its answers scored —
these are the first place to look before drafting anything new.

One folder per win, named `YYYY-MM-buyer-short-title`, containing the submitted
documents and, where you have it, the buyer's scoring feedback.

## Important

The actual documents are **not** committed to git — see `../.gitignore` and the
note in `../README.md`. Keep them in OneDrive/SharePoint. This folder tracks
what exists and what has been harvested from each win.

## Harvesting a win

After each win, pull the reusable parts out so the next bid starts further
along:

1. **Answers** → `../library/answer-bank.md`, with the question it answered and
   the score if you know it.
2. **Contract references** → `../library/past-performance.md`.
3. **Company facts** (turnover, headcount, insurance, certifications)
   → `../library/company-profile.md`.
4. **Metrics** (defect rates, response times, satisfaction scores)
   → the metrics table in `../library/past-performance.md`.
5. **Anything that was wrong or inconsistent** → fix it at source before it
   gets copied into the next bid.
