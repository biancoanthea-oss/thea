# Past performance

Case studies and contract references, written once and reused. Most tenders
ask for two or three references of similar scope, value and complexity — having
these ready in a consistent format saves days.

Last reviewed: [DATE]

## How to write one that scores

Use **CAR**: Context → Action → Result. The Result must carry a number and a
date. "Improved efficiency" scores nothing; "reduced average response time from
48 to 19 hours within four months, sustained for the remaining 26 months of the
contract" scores.

Check with the client before naming them, and keep the reference contact's
permission current — buyers do call them.

| Can we name the client publicly? | Yes / No / With approval |

**Context.** What the client needed and why, including any difficulty that
makes this comparable to the tender you're bidding.

**Action.** What we actually did — the delivery model, the people, the
timescales, the specific decisions that mattered. Be concrete enough that
someone in the same industry recognises real work.

**Result.** Measured outcomes with numbers and dates. Include KPI performance,
client feedback or satisfaction scores, contract extensions, and anything that
went wrong plus how it was resolved — a reference with one honest recovery
story is more credible than an unbroken run of perfection.

**Relevance to this tender.** One sentence, rewritten per bid.
