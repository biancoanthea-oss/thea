# Archived bids

Submitted, closed, or no-bid opportunities. Keep them — the archive is the
most useful writing resource you have. Before drafting anything new, check
whether a similar question has already been answered here.

Move a folder in once `06-lessons-learned.md` is complete.

Worth keeping even for a no-bid: the brief and the decision record explain to
future-you why you passed, and what would have to change to bid next time.
