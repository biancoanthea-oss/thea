# Source documents

Put the buyer's original files here, unmodified: the ITT, specification, terms
and conditions, pricing schedule, selection questionnaire, clarification
responses, and any addenda.

Keep the buyer's own filenames, and never edit these files — they're the
reference every answer is checked against.

Suggested naming when you add versions or clarifications:

```
ITT.pdf
Specification.pdf
Pricing-Schedule.xlsx
Clarifications-2026-03-14.pdf
Addendum-01.pdf
```

If the buyer reissues a document, keep both and note which is current in
`../01-bid-brief.md`. Late addenda that change requirements are a classic way
to lose a bid you'd otherwise have won.
