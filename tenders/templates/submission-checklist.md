# Submission checklist

Copy into the bid folder and work through it the day before submission, not
the hour before. Most lost bids are lost on process, not prose.

## Content

- [ ] Every question answered, in the buyer's numbering
- [ ] Every sub-clause of every question covered
- [ ] Every word/character limit met — counted, not estimated
- [ ] Compliance matrix fully closed out
- [ ] No placeholders left anywhere (search for `[`, `TBC`, `XXX`, `TODO`)
- [ ] No other buyer's name left in from a reused answer — the classic
      copy-paste failure, and it costs credibility instantly
- [ ] Every figure traceable to a real source
- [ ] Client names used only where permission is confirmed
- [ ] Spelling and grammar checked in the ITT's language variety
- [ ] Read once out loud, or by someone who didn't write it

## Format

- [ ] Buyer's own templates used, unmodified in structure
- [ ] Font, size, margins and page limits as specified
- [ ] File formats as specified (PDF vs editable — some require both)
- [ ] File naming convention followed exactly
- [ ] File sizes within portal limits
- [ ] Documents are text-searchable, not scans, unless scans are required
- [ ] No tracked changes, comments, or metadata left in files

## Attachments

- [ ] Every document referenced in an answer is actually attached
- [ ] Every attachment named as it is referenced
- [ ] Certificates in date at submission **and** at contract start
- [ ] Signatures applied where required
- [ ] Pricing schedule complete, arithmetic checked independently

## Portal

- [ ] Logged in and the submission area located well in advance
- [ ] Every upload slot filled with the correct file
- [ ] **Submit pressed** — uploading is not submitting, and portals do not
      submit for you at the deadline
- [ ] Confirmation receipt downloaded and saved to the bid folder
- [ ] Screenshot of the submitted state saved

## After

- [ ] Calendar reminder for the award date
- [ ] Debrief requested when the outcome lands
- [ ] `06-lessons-learned.md` started within a day
